# 🌶️ คู่มือระบบบริหารจัดการร้านอาหาร "ฟ้าใสตำนัว"
### (Fahsai Tumnua - Restaurant Management System & Smart POS)

ระบบบริหารจัดการร้านอาหารแบบครบวงจร พัฒนาขึ้นด้วยภาษา **Python** และเฟรมเวิร์ก **Streamlit** เชื่อมต่อฐานข้อมูล **SQLite** ออกแบบเพื่อรองรับการสั่งอาหารผ่านคิวอาร์โค้ดประจำโต๊ะ (QR Code Ordering System) ควบคู่กับจอแสดงผลในห้องครัวและระบบแคชเชียร์คิดเงิน (Kitchen Display System & POS) รวมถึงระบบบริหารจัดการเมนูอาหาร สมาชิกสะสมแต้ม และรายงานสถิติยอดขาย

## 1. ภาพรวมสถาปัตยกรรมระบบ

ระบบถูกออกแบบโดยแบ่งการทำงานออกเป็น 2 ส่วนหลักผ่านการตรวจสอบพารามิเตอร์ URL (`st.query_params`):
- **โหมดผู้ดูแลระบบและหลังร้าน (`?mode=admin`):** สำหรับเจ้าหน้าที่ ผู้จัดการ แคชเชียร์ และแม่ครัว ควบคุมการทำงานผ่านหน้าต่างแดชบอร์ด 5 หมวดหมู่หลัก
- **โหมดลูกค้าสั่งอาหารประจำโต๊ะ (`?table=N`):** สำหรับลูกค้าที่สแกน QR Code ประจำโต๊ะอาหาร แสดงรายการอาหาร 10 หมวดหมู่ 131 เมนูมาตรฐาน พร้อมรูปภาพความละเอียดสูงที่ได้รับการบีบอัดเพื่อประสิทธิภาพสูงสุด

## 2. คู่มือการใช้งานสำหรับผู้ดูแลระบบ (Admin & Back-office)

### 2.1 การเข้าสู่ระบบและการรักษาความปลอดภัย
- **การเข้าใช้งาน:** เข้าผ่าน URL ที่มีพารามิเตอร์ `?mode=admin`
- **ระบบรักษาความปลอดภัย:** รหัสผ่านได้รับการเข้ารหัสทางคณิตศาสตร์ด้วยอัลกอริทึม **SHA-256 ผสมค่า Salt (Salted Cryptographic Hash)** ป้องกันการโจมตีประเภท Dictionary Attack และ Rainbow Table
- **ข้อมูลการเข้าสู่ระบบเริ่มต้น:**
  - **ชื่อผู้ใช้งาน (Username):** `admin` (รองรับการพิมพ์แบบ Case-Insensitive ไม่แบ่งแยกตัวพิมพ์เล็ก-ใหญ่)
  - **รหัสผ่านเริ่มต้น (Password):** `adminfahsaitumnua@12`
- **การคงสถานะเซสชัน:** ระบบจดจำสถานะผ่าน `st.session_state` เพื่อความปลอดภัย เมื่อเสร็จสิ้นการปฏิบัติงานสามารถกดปุ่ม **"🚪 ออกจากระบบ"** เพื่อสิ้นสุดเซสชันทันที

### 2.2 การเปลี่ยนรหัสผ่านผู้ดูแลระบบ
- ผู้ดูแลระบบสามารถกดปุ่ม **"🔑 เปลี่ยนรหัสผ่าน"** ที่แถบเครื่องมือด้านบน
- ระบบจะแสดงหน้าต่างแบบป๊อปโอเวอร์ (Popover) กำหนดให้กรอก:
  1. รหัสผ่านเดิม (เพื่อยืนยันตัวตน)
  2. รหัสผ่านใหม่ (ต้องมีความยาวไม่น้อยกว่า 6 ตัวอักษร)
  3. ยืนยันรหัสผ่านใหม่อีกครั้ง
- เมื่อบันทึกสำเร็จ รหัสผ่านใหม่จะถูกแปลงเป็น Salted Hash ชุดใหม่และจัดเก็บลงฐานข้อมูลถาวรโดยไม่มีการรีเซ็ตค่ากลับ

### 2.3 แท็บที่ 1: การจัดการโต๊ะอาหารและการสร้าง QR Code
- **ระบบโต๊ะเริ่มต้น:** ระบบกำหนดโต๊ะอาหารเริ่มต้นจำนวน 10 โต๊ะ (โต๊ะที่ 1 ถึง โต๊ะที่ 10) พร้อมใช้งานทันที
- **การเพิ่มโต๊ะใหม่:** กำหนดหมายเลขโต๊ะและชื่อเรียกเฉพาะ (เช่น *"โต๊ะที่ 11"*, *"ซุ้มริมสวน 1"*, *"ห้อง VIP แอร์"*) ระบบจะสร้างฐานข้อมูลพร้อมแสดงผลทันที
- **การสร้าง QR Code ประจำโต๊ะอัตโนมัติ:** ทุกโต๊ะอาหารจะมีภาพ QR Code ที่เชื่อมโยงกับ URL ของโต๊ะนั้นโดยตรง (`?table=N`) สามารถพิมพ์ภาพเพื่อติดประจำโต๊ะจริงได้ทันที
- **การติดตามสถานะโต๊ะอาหาร:**
  - `🟢 โต๊ะว่าง`: พร้อมรับลูกค้ารายใหม่
  - `🟠 มีออเดอร์ค้าง`: มีรายการอาหารกำลังปรุงหรือรอเสิร์ฟ
  - `🔵 เช็คบิลแล้ว`: ชำระเงินเรียบร้อย รอพนักงานทำความสะอาดและเคลียร์โต๊ะ
- **การล้างสถานะโต๊ะ (เคลียร์โต๊ะ):** เมื่อลูกค้ารับประทานเสร็จสิ้นและชำระเงินเรียบร้อย สามารถกดปุ่ม **"🧹 ล้างสถานะโต๊ะ"** เพื่อรีเซ็ตหน้าจอโต๊ะนั้นให้พร้อมสำหรับลูกค้ารายต่อไป โดยยอดขายในระบบยังคงบันทึกไว้ครบถ้วน

### 2.4 แท็บที่ 2: ระบบจอครัวและเคาน์เตอร์คิดเงิน (POS)
- **ระบบแจ้งเตือนออเดอร์อัตโนมัติ:** หน้าจอครัวจะทำการรีเฟรชข้อมูลแบบเรียลไทม์ทุก 3 วินาที พร้อมส่งสัญญาณเสียงกระดิ่งเตือนเมื่อมีรายการสั่งใหม่
- **การจัดการสถานะอาหารรายจาน:** แม่ครัวสามารถควบคุมขั้นตอนการประกอบอาหารแต่ละรายการได้อย่างละเอียด:
  - `⏳ รอปรุง (Pending)` ➔ `🍳 กำลังปรุง (Cooking)` ➔ `🍲 ปรุงเสร็จ (Cooked)` ➔ `✅ เสิร์ฟแล้ว (Served)`
- **เคาน์เตอร์คิดเงินและออกใบเสร็จ:**
  - แสดงสรุปยอดรวมค่าอาหาร ส่วนลดสมาชิก และยอดสุทธิ
  - มีช่องทางแสดงภาพ QR Code ธนาคารสำหรับให้ลูกค้าสแกนชำระเงินผ่านระบบพร้อมเพย์
  - เมื่อรับชำระเงินเรียบร้อย สามารถกดปุ่ม **"ปิดบิล / ชำระเงินสำเร็จ"** เพื่อบันทึกยอดขายและคำนวณแต้มสะสมให้สมาชิกโดยอัตโนมัติ

### 2.5 แท็บที่ 3: รายงานสถิติและอันดับเมนูขายดี
- **ตัวชี้วัดสำคัญ (Key Metrics):** แสดงจำนวนจานที่จำหน่ายได้รวม, ยอดขายรวม (บาท), และเมนูยอดนิยมอันดับที่ 1
- **ทำเนียบเมนูยอดนิยม (Podium):** แสดงแท่นรางวัลเกียรติยศสำหรับ 3 เมนูที่มียอดขายสูงสุด
- **ตารางวิเคราะห์ความนิยม:** แสดงตารางจำแนกตามจำนวนจาน ยอดเงินรวม พร้อมแถบแสดงสัดส่วนยอดขาย
- **ตัวกรองข้อมูล:** รองรับการเลือกดูรายงานแบบ "เฉพาะวันนี้" หรือ "ประวัติยอดขายทั้งหมด"

### 2.6 แท็บที่ 4: ทะเบียนประวัติลูกค้าและระบบสมาชิกสะสมแต้ม
- **การจัดเก็บข้อมูล:** บันทึกข้อมูลเฉพาะที่จำเป็น ได้แก่ ชื่อ, นามสกุล และหมายเลขโทรศัพท์
- **เกณฑ์การคำนวณคะแนนสะสม (Earning Rules):**
  - ทุก **100 บาท** ของยอดชำระเงินสุทธิ จะได้รับ **1 คะแนน**
- **เกณฑ์การแลกรับส่วนลด (Redemption Rules):**
  - ทุก **10 คะแนน** สามารถแลกรับส่วนลดได้ **25 บาท**
  - การแลกคะแนนต้องเป็นทวีคูณของ 10 คะแนน (เช่น 10, 20, 30 คะแนน แลกได้ 25, 50, 75 บาท ตามลำดับ)
  - ส่วนลดจะต้องไม่เกินยอดค่าอาหารสุทธิ
- **ทำเนียบสมาชิกระดับพรีเมียม:** จัดอันดับลูกค้าตามคะแนนสะสมสูงสุด พร้อมแสดงประวัติความถี่ในการเข้าใช้บริการและยอดการใช้จ่ายสะสม

### 2.7 แท็บที่ 5: การบริหารจัดการรายการอาหาร (เพิ่ม/ลบเมนู)
- **การเพิ่มเมนูอาหารใหม่:** ฟอร์มบันทึกข้อมูลประกอบด้วย:
  1. ชื่อเมนูอาหาร (มีระบบตรวจสอบชื่อซ้ำในฐานข้อมูลอัตโนมัติ)
  2. หมวดหมู่อาหาร (เลือกจาก 10 หมวดหมู่หลัก หรือสร้างชื่อหมวดหมู่ใหม่)
  3. ราคาขายต่อหน่วย (บาท)
  4. ต้นทุนวัตถุดิบต่อหน่วย (บาท) พร้อมระบบคำนวณกำไรเบื้องต้นและอัตราส่วนกำไร (Margin %)
  5. ที่อยู่รูปภาพ (รองรับทั้ง Web URL เช่น `https://...` และไฟล์รูปภาพภายในโฟลเดอร์ `static/img/menu/`)
  6. คำอธิบายรายละเอียดเมนู
- **การค้นหาและกรองเมนู:** ค้นหาได้อย่างรวดเร็วตามชื่อเมนู คำอธิบาย หรือกรองตามหมวดหมู่
- **การลบเมนูอาหาร:** มีปุ่มลบรายการอาหารพร้อมหน้าต่างยืนยันความถูกต้อง (Confirmation Popover) เพื่อป้องกันการลบข้อมูลโดยอุบัติเหตุ

## 3. คู่มือการใช้งานสำหรับลูกค้า (Customer Self-Ordering)

### 3.1 การเข้าสู่หน้าเมนูอาหารและการสลับโต๊ะ
- ลูกค้าใช้สมาร์ตโฟนสแกน QR Code ประจำโต๊ะอาหาร ระบบจะเปิดหน้าเมนูอาหารตามหมายเลขโต๊ะนั้นทันที
- **ระบบสลับ/เลือกโต๊ะ:** หากลูกค้าเปิดใช้งานผ่านลิงก์โดยตรง สามารถกดปุ่ม **"🔄 สลับ / เปลี่ยนโต๊ะอาหาร"** เพื่อระบุหมายเลขโต๊ะที่ตนเองนั่งได้อย่างถูกต้อง

### 3.2 การเลือกรายการอาหารและการจัดการตะกร้า
- รายการอาหารจัดเรียงตาม 10 หมวดหมู่มาตรฐาน:
  1. ตำนัว | 2. ตำพรีเมียม | 3. ยำแซ่บ | 4. ลาบ & ก้อย & น้ำตก | 5. ย่าง & ทอด
  6. ต้มแซ่บ & แกงอีสาน | 7. อาหารจานเดียว | 8. ของหวาน | 9. เครื่องเคียง & ข้าว | 10. เครื่องดื่ม
- ลูกค้าสามารถกดปุ่ม **"➕ เพิ่ม"** บนการ์ดอาหาร และปรับเพิ่ม/ลดจำนวนผ่านปุ่ม Stepper (`➖` / `➕`) ได้โดยตรง
- ในหน้าต่างตะกร้าสินค้า สามารถระบุข้อความพิเศษเพิ่มเติมสำหรับแต่ละจานได้ เช่น *"เผ็ดน้อย"*, *"ไม่ใส่ชูรส"*, *"แยกน้ำยำ"*

### 3.3 การใช้สิทธิประโยชน์สมาชิกและแลกคะแนนส่วนลด
- ลูกค้าสามารถกรอกหมายเลขโทรศัพท์ในกล่องระบบสมาชิก (ไม่บังคับ)
- ระบบจะตรวจสอบคะแนนคงเหลือ หากมีสิทธิ์แลกคะแนน ลูกค้าสามารถเลือกจำนวนแต้มที่ต้องการนำมาเป็นส่วนลดได้ด้วยตนเองก่อนยืนยันรายการ
- หากยังไม่เป็นสมาชิก สามารถกรอกชื่อ-นามสกุลเพื่อสมัครสมาชิกได้ทันทีในขั้นตอนเดียว

### 3.4 การติดตามสถานะการปรุงอาหารแบบเรียลไทม์
- เมื่อกดยืนยันส่งออเดอร์ ข้อมูลจะถูกส่งตรงเข้าห้องครัวทันที
- หน้าจอจะแสดงแถบความคืบหน้า (Progress Bar) และอัปเดตสถานะอัตโนมัติทุก 3 วินาที:
  - `⏳ รอร้านรับออเดอร์ (25%)`
  - `🍳 ครัวกำลังปรุงอาหาร (45%)`
  - `🍲 ปรุงเสร็จ กำลังทยอยเสิร์ฟ (75%)`
  - `🍽️ เสิร์ฟถึงโต๊ะครบแล้ว (100%)`
  - `✅ เช็คบิลเรียบร้อยแล้ว`

## 4. โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้งานฐานข้อมูล **SQLite (`restaurant.db`)** ประกอบด้วย 6 ตารางหลัก:

| ชื่อตาราง | วัตถุประสงค์การใช้งาน | ฟิลด์ข้อมูลหลัก |
| :--- | :--- | :--- |
| `menu_items` | รายการอาหารของทางร้าน | `id`, `name`, `category`, `price`, `cost`, `image`, `description` |
| `tables` | ข้อมูลโต๊ะอาหารและสถานะ | `id`, `table_number`, `name`, `status` |
| `orders` | ใบสั่งซื้อ / บิลหลัก | `id`, `table_id`, `status`, `subtotal`, `discount`, `total_price`, `points_used`, `points_earned`, `member_phone`, `created_at` |
| `order_items` | รายการอาหารย่อยในแต่ละบิล | `id`, `order_id`, `item_name`, `price`, `cost`, `quantity`, `note`, `status` |
| `members` | ข้อมูลสมาชิกลูกค้า | `id`, `first_name`, `last_name`, `phone`, `points`, `created_at` |
| `admin_users` | บัญชีผู้ดูแลระบบหลังร้าน | `id`, `username`, `password_hash`, `salt`, `full_name`, `role`, `created_at` |

## 6. ขั้นตอนการติดตั้งและเริ่มใช้งานบนเครื่องแม่ข่าย (Deployment Guide)

### 6.1 ข้อกำหนดเบื้องต้น (Prerequisites)
- ภาษา **Python 3.10** หรือ **3.11** (แนะนำ)
- ตัวจัดการแพ็กเกจ **pip**

### 6.2 การติดตั้งในเครื่องคอมพิวเตอร์ (Localhost)
1. เปิดโปรแกรม Terminal หรือ PowerShell แล้วนำทางไปยังโฟลเดอร์ของโครงการ:
   ```bash
   cd c:\Users\ADVS\Documents\chatGPT_img\restaurant_system
   ```
2. ติดตั้งแพ็กเกจที่จำเป็นตามรายการใน `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
   *(หรือติดตั้งเฉพาะแพ็กเกจหลัก: `pip install streamlit qrcode pillow`)*
3. เริ่มต้นการทำงานของเซิร์ฟเวอร์:
   ```bash
   streamlit run app.py
   ```
4. ระบบจะเปิดหน้าต่างเบราว์เซอร์อัตโนมัติที่ที่อยู่: `http://localhost:8501`

### 6.3 การใช้งานบนระบบคลาวด์ (Streamlit Community Cloud)
- **URL สำหรับลูกค้าสั่งอาหาร (เช่น โต๊ะ 1):**
  `https://<your-subdomain>.streamlit.app/?table=1`
- **URL สำหรับผู้ดูแลระบบหลังร้าน (Admin Dashboard):**
  `https://<your-subdomain>.streamlit.app/?mode=admin`
